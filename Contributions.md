# Contributing Guidelines

**IMPORTANT WARNING: NEVER commit directly to the `main` branch!**

## 1. Branches & Pull Requests
- Create a new branch named after your feature (e.g., `YOLO-extra-feature`, `Camera-Holes-Design`).
- Work **only** on that feature in your branch.
- Open a Pull Request (PR) to the `main` branch when done.
- Notify the team via message.
- Review PRs together if needed.

## 2. Commit Messages
- Format: `<Word>: <Short description>`
- Allowed words: `add`, `update`, `change`, `delete`.
- Example: `add: camera holes to drone CAD`
